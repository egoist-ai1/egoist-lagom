# Egoist Lagom — проверочный walkthrough

Этот документ описывает безопасную проверку сборки без изменения рабочей системы.

## Локальная проверка

```powershell
npm ci
npm run build
npm test
```

Тесты проверяют IPC-контракты, DNS/DoH readback, сохранение пользовательских настроек, состояние Windows-служб, транзакционный откат, короткие анимации и узкие макеты.

## Установщик

Packaging запускается только на Windows x64:

```powershell
$env:SHIELD_EVIDENCE_DIR = '<absolute evidence directory>'
npm run package:win
```

Установщик запрашивает права администратора, освобождает собственные процессы и службы по каноническим путям, создаёт журнал транзакции и публикует SHA-256 рядом с EXE. При ошибке новая версия не считается установленной.

## Визуальная проверка

Headless UI checks используют локальные mock-данные и сохраняют PNG в переданную папку evidence. Проверяются размеры 512×364, 550×370 и 1440×940, фокус клавиатуры, Escape, reduced motion, кнопки релиза и строки журнала.

## Границы

Локальные проверки не заменяют чистую Windows 10/11 acceptance-среду. Для неё нужны отдельная VM, штатный UAC, перезагрузка и последовательность install → update → reboot → uninstall. Не прикладывайте в issue журналы с токенами, адресами и личными данными.
