# Egoist Lagom 3.7.8

Core самостоятельно наблюдает за установленными автоматическими службами, сохраняет явное выключение и ограничивает восстановление зависших процессов. Открытый интерфейс для этой работы не требуется. DNS refresh проверяет выбранный HTTPS endpoint и кандидаты IP до изменения конфигурации, сохраняет journal/rollback и исходные DNS адаптеров по GUID и семействам.

Telegram readiness теперь требует своего SCM/process listener: чужой ответ не считается успехом, занятый или неизвестный порт блокирует запуск. Явный standalone Zapret отключает автозапуск остановленной регистрации; временное отключение для VPN сохраняет его. Смена профиля сохраняет регистрацию и восстанавливает прежнюю конфигурацию при ошибке.

Исправлены конкурирующие UI действия, устаревшие ответы, доступность ошибок при масштабе 200%, лишняя постоянная анимация и повторное скачивание обновления после обрыва. Обновление существующего приложения проходит защищённую staging/backup/watchdog процедуру. Undici — 7.29.1; Core runtime — .NET 10.0.12.

Проверка: 484/484 Node тестов без пропусков, 22 группы Core, 12 группы полного C# кода/native DNS, настоящий локальный Xray/TLS, 20 installer ownership checks и readback установленного пакета без интерфейса. Нагрузочные 90 дней/шесть часов используют виртуальное время; реальных месяцев uptime и reboot smoke в этом аудите нет.

Переход с 3.7.7 и старше требует ручного проверенного installer: утрачен прежний private signing key, 3.7.8 содержит новую цепочку доверия. Подписи проверяются; Ed25519 подпись обновления не заменяет Windows Authenticode certificate. После ручного перехода следующие обновления проверяются новым root.

Сохранённый legacy Xray DNS обслуживает A/AAAA; TXT/MX/SRV/HTTPS остаются ограничением этого backend. Новый стандартный DoH на поддерживаемой Windows выбирает native backend. Существующий local режим не переносится автоматически. VPN recovery требует работающего приложения. Доступный свой Telegram listener не доказывает доставку удалённого трафика.
