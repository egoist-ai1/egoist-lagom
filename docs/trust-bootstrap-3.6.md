# Переход на 3.6.1

Закрытые ключи прежнего канала обновления были утеряны. Версия 3.6.1 использует новый корневой ключ и release key `release-2026-09`. Это новый источник доверия, который невозможно подтвердить подписью прежнего корневого ключа.

1. Откройте релиз `v3.6.1` в официальном репозитории `egoist-ai1/egoistshield`.
2. Скачайте установщик и сравните SHA-256 с файлами этого релиза.
3. Установите версию вручную. Она закрепит новый root registry для последующих обновлений.

SHA-256 нового файла `root-public-key.pem`:

```text
3c5b24f9247110000f70a77e1e8a60157166f9675f6c59bd021c6e45d4eda592
```

Совпадение хэша с файлом на той же странице само по себе не создаёт независимого доверия к издателю. Источник новой установки выбирается вручную. Старые клиенты продолжают отклонять неизвестный ключ; обхода проверки Ed25519 нет.

Исходники восстановлены из проверенной официальной сборки 3.5.4 и сохранены владельцем в приватном репозитории. Исходные release assets 3.5.4 сохранены. Authenticode-подписи у новой сборки нет.
