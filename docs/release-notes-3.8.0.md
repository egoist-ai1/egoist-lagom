# Egoist Lagom 3.8.0

Эта версия улучшает фоновую работу, установку поверх старых служб и управление сетью. Включённая пользователем фоновая служба использует сохранённую конфигурацию и работает независимо от окна приложения. Сохранение настроек и применение их к уже работающему соединению показываются как отдельные действия.

- Добавлен фоновый VPN с защищённым снимком сервера и правил, автоматическим запуском службы и восстановлением собственного runtime после аварии. Временное подключение и фоновая служба не запускают два TUN одновременно.
- Установщик согласует остановку служб с их восстановлением, сохраняет намерения запуска и передаёт управление от старого helper новому. Настройка «не открывать приложение после обновления» сохраняется. Завершение собственного процесса подтверждается сигналом Windows по удерживаемому дескриптору; подтверждённо завершившийся процесс в системном снимке не считается перезапуском.
- Исправлен реальный отказ чистой установки на Windows с виртуальным адаптером без DNS-записей. Откат учитывает только снятые DNS-семейства и сохраняет настройки сторонних интерфейсов.
- Core различает повреждённое, отсутствующее и недоступное состояние. Неизвестный результат аварийной операции блокирует повторное изменение до восстановления.
- Ужесточены проверка DNS-пакетов, отмена запросов, ограничения HTTP/TLS и проверка принадлежности процесса и listener. Состояние «подключено» требует подтверждения; SCM Running сам по себе не считается доступным маршрутом.
- В настройках доступны режим маршрутизации, DNS VPN, TUN и упорядоченные правила доменов/процессов. Запись проверяет ревизию и подтверждается после сохранения на диск. Применение новой конфигурации фоновой службы требует отдельного действия.
- Исправлены наложение галочки на power icon при наведении, перекрытие кнопок уведомлениями, focus редактора и поведение неизвестных состояний. Чёрно-белый интерфейс сохраняет compact/full режимы; большие списки серверов разбиты на страницы с поиском по полному набору.
- Окно приложения запускается от администратора через штатный Windows UAC. Фоновые службы остаются под управлением Core и работают без окна. Сохраняются проверка исполняемых файлов, ASAR integrity и проверка запросов Core.
- Автозапуск окна по явной настройке пользователя использует защищённую задачу Планировщика с повышенными правами для того же пользователя. При обновлении задача приостанавливается до восстановления служб и DNS; её прежнее намерение возвращается после проверки. Ручное закрытие окна не вызывает его перезапуск.

Для 3.7.8 и 3.7.9 сохранена проверка обновлений через действующую цепочку доверия. Для 3.7.7 требуется однократная ручная установка: её прежний доверенный ключ не позволяет безопасно подтвердить новый канал. Проверка подписи не отключается. Release metadata связывает точный исходный commit, байты установщика и package-integrity.json.

Подробные результаты, неудачные прогоны и границы проверки находятся в `Egoist-Lagom-validation.md` и [отчёте аудита](https://github.com/egoist-ai1/egoist-lagom/tree/codex/lagom-production-audit/docs/product-hardening-2026-10-01). Короткие стресс-тесты не дают гарантии многомесячной работы. Доступность внешнего сервера и сеть провайдера остаются внешними условиями.

Установщик не подписан Authenticode. Подпись Ed25519 относится к метаданным обновлений; контрольные суммы установщика опубликованы отдельно.
