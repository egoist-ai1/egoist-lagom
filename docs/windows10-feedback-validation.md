# Проверка отзыва о Windows 10

В отзыве автоподбор показывает ошибки примерно «6 из 17», ручной запуск выбранного профиля работает, а основная кнопка после ожидания сообщает об ошибке. DNS и Telegram, по словам пользователя, работают. Автозапуск не проверен. Скриншот не содержит версию curl, ошибки отдельных HTTPS-запросов и версию установленного пакета; точную причину на этом компьютере пока нельзя установить.

## Воспроизведённый дефект

Функция `probeCurlHeadUrl` выполняла GET и скачивала тело страницы с пределом 2 МиБ. В интеграционном тесте настоящий Windows curl получал HTTP 200, но возвращал код 63 (`Maximum file size exceeded`); доступная страница считалась недоступной. Проверка теперь выполняет HEAD, следует перенаправлениям и принимает конечный успешный HTTP-статус. Если сервер отвечает 405 или 501, выполняется один GET с ограниченным диапазоном и размером, в оставшееся время проверки. Проверка сертификата и таймаут сохранены. Это проверка доступности HTTP, а не доказательство воспроизведения видео или голосовой связи.

Гостевая Windows 10 также воспроизвела второй дефект: запрос состояния профилей завершался на `Get-CimInstance Win32_Process` и возвращал `OPERATION_FAILED`. Код больше не использует WMI для поиска и завершения `winws.exe`. `Get-Process` возвращает PID, путь и время запуска, а перед остановкой код повторно сравнивает точный путь процесса. Core выполняет эту операцию как автоматическая служба `LocalSystem`; чужой одноимённый процесс не завершается.

## Регрессии

- Настоящий системный curl: большая доступная страница; перенаправление; отказ HTTP 403; сервер без поддержки HEAD; отмена ожидающего запроса.
- 22 профиля с шестью успешными вспомогательными целями из 17: нет выдуманного победителя, запись рекомендации не выполняется, кандидаты останавливаются.
- Ручной и автоматический запуск одного профиля: одинаковые исполняемый файл, аргументы и рабочая папка, включая кириллицу и пробелы.
- Основная кнопка при неудачном выборе: нет статуса успешного подключения или записи автозапуска; уже работающие DNS и Telegram сохраняются.
- Отмена, повторные нажатия, сбой запуска/остановки службы, восстановление DNS, независимые переключатели и переносы журнала покрыты общим набором.

Локально после исправления: **335/335** тестов, **22/22** проверки компоновки и клавиатуры, **10/10** сценариев виджета, **10/10** действий интерфейса. Проверки интерфейса используют тестовые ответы API. Это не заменяет гостевой прогон Windows 10/11.

## Приёмка на каждой виртуальной машине

Зафиксировать версию Windows, системного curl и SHA-256 установщика. Провести чистую установку, запуск, ручной старт и остановку одного профиля, автоподбор того же набора и подключение основной кнопкой. Сохранить ошибки всех HTTPS-целей, сравнить аргументы запуска, проверить отмену во время выбора и отсутствие оставшихся процессов. Отдельно проверить DNS и Telegram, закрытие окна, перезагрузку с включённым и выключенным автозапуском, обновление поверх установленной версии, удаление и повторную установку. После остановки и удаления сверить DNS и системный прокси с исходным состоянием.

Новый финальный релиз не подтверждён до завершения этой приёмки. Старый установщик не содержит описанное здесь исправление.
