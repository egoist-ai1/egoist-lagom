# Валидация Egoist Shield 3.6.1

Статус: завершено 10 сентября 2026 года. Проверен именно кандидат 3.6.1 с установщиком размером 194 061 516 байт. Публикация использует подписанный Ed25519-манифест `release-2026-09`; Authenticode-подписи у установщика нет.

| Проверка | Подтверждённый результат |
| --- | --- |
| Автоматические регрессии | 75/75 JavaScript-тестов проходят. Дополнительно проходят синтаксические проверки JavaScript, разбор PowerShell установщика и `tests/installer-regressions.ps1`. Проверяются границы Core-команд, восстановление runtime и сетевых настроек, DNS URL, XHTTP, замена TUN-сессий, токен администратора, локализованный статус служб и завершение приложения. |
| Удаление управления Windows | Экран «Система», IPC/preload API и механики Windows Update/Defender удалены из UI, Core и установщика. Запросы удалённых операций отклоняются Core, старый адрес открывает обзор, а установленный renderer подтверждает отсутствие retired Windows controls. |
| Конфигурации runtime | 18 конфигураций sing-box проверены реальным executable; XHTTP/TUN-конфигурация проверена Xray. Конфигурационная проверка сама по себе не обещает доступность внешнего сервера. |
| Интерфейс | Компактный набор проверок: 20/20 сценариев настроек и диалогов, включая клавиатуру и масштаб 200%, и 9/9 проверок renderer actions. Установленный Electron на Windows 10 и Windows 11 прошёл все шесть экранов: dashboard, VPN, DNS, Запрет, Telegram Proxy и настройки. На обоих гостях подтверждены видимость, отсутствие горизонтального переполнения и отсутствие старого управления Windows. |
| Анимация | Постоянная фоновая анимация удалена. Переходы экранов используют короткое изменение прозрачности, а reduced motion отключает переходы. Результат относится к текущей вёрстке и не переносит старые измерения иллюстрации. |
| Чистая установка | Windows 10 LTSC 2021 x64 (build 19044) и Windows 11 Pro x64 (build 26200) установили ровно этот кандидат. Core-служба запустилась, опциональные компоненты и активационные флаги остались выключенными, исходные DNS и отключённый пользовательский прокси сохранились. Проверены версия 3.6.1, хэши payload и отсутствие устаревшего control helper. |
| Компоненты | На обеих ОС через защищённый Core проверены System DoH, Telegram Proxy и Запрет. System DoH применился, разрешил контрольный домен через реальный Xray и восстановил адреса DNS адаптера; Telegram-служба слушала локальный порт и остановилась; Zapret с WinDivert-службой запустился и остановился. Mutation на query endpoint отклонена. |
| Откат | На обеих ОС транзакционная подготовка и rollback восстановили точный executable и работающую Core-службу, сохранили DNS и не остановили посторонний `winws.exe` с тем же именем. Журнал восстановления сохранён при штатном rollback. |
| Удаление | На обеих ОС тихий uninstaller завершился с кодом 0, удалил принадлежащие Shield файлы, службы и запись удаления, сохранив DNS, процесс и данные постороннего приложения. |
| VPN и TUN | На обеих ОС окончательный пакет прошёл реальные контролируемые TCP и XHTTP маршруты в режимах proxy и TUN. Для каждого маршрута подтверждены `isMock=false`, подключение, внешний egress, диагностика, отключение, восстановление прокси и повторное подключение TUN; для TUN проверены маршрут системы и совпадение прямого egress. Проверены как Xray, так и sing-box runtime. |
| Внешняя подписка | HTTPS-выход ранее подтверждён для обновлённой подписки. Три выбранных узла последней подписки принимают TCP, но завершают TLS/HTTPS по таймауту; прямой IP не устранил отказ. Доступность этих узлов не заявляется как часть релиза. |
| Подписи и состав | Setup SHA-256: `eeebb8636eb9214fd0bf9ad98949d31e07fc19f5993a0e9637ab9910a7d0b522`. `app.asar`: `ea3bce7559525802f98bbd21a888041b8ff4af05bfb807a310ca882a5451f629`; component worker: `d2093dcdd4d45c9e476340738851318c4c06119db426f1c0b371732b2b81f15d`; Core: `a775d92a64a39ac39c32d684badd24052d3b3e1ed3d1368d889e20dc082c9594`; `owned-cleanup.ps1`: `095ed6c7987c9918bc1ea12abf38a6a85790f03d277cfbe50f2475ecee729185`. Runtime manifest: 15 855 байт, SHA-256 `83e4c9eef845ce1f12458d910acc5efab8c0e644503691a69eabf897fb252b6e`; в нём Xray содержит Wintun и шесть файлов. Manifest и registry проверяются Ed25519-цепочкой `release-2026-09`. |

Гости: Windows 10 Enterprise LTSC 2021 x64 (19044) и Windows 11 Pro x64 (26200), QEMU с программной эмуляцией. Проверялись настоящие гостевые службы, драйверы, установщик и executable. Испытания не охватывают все физические конфигурации, ARM и x86.

Исходники восстановлены из официальной 3.5.4 и сохранены в приватном репозитории владельца. Переход со старого корневого ключа требует [ручной установки](trust-bootstrap-3.6.md).
