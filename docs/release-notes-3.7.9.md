# Egoist Lagom 3.7.9

Проверка Telegram-прокси больше не запускает два PowerShell-процесса на каждое чтение состояния. Core проверяет SCM, TCP-слушатель, путь процесса, PID, время создания и цепочку предков через Windows API. Чужой или неизвестный владелец не считается рабочей службой.

Обновлён полный Electron runtime до 44.4.5. Упаковка проверяет официальный SHA-256 и фактическую пригодность пакета к установке до сжатия. Исправлены удержание каталога при rollback и сообщение о незавершённом откате файлов.

Уточнены состояния запуска служб и ошибки интерфейса. Обновлены шесть SVG-иконок, фокус и Escape в диалогах, узкая легенда и переходы экранов. Короткая анимация сразу показывает содержимое; скрытый запуск сохраняет скрытое окно. При наведении на подключённый мини-щит галочка скрывается до появления выключателя; при уходе курсора символы также не накладываются.

Фоновые проверки обновлений выполняются последовательно, с увеличением интервала после сетевого отказа. Установка ждёт завершения сетевых операций и отключённого VPN. Явное выключение службы и настройка автообновлений сохраняются.

**Переход с 3.7.7 и более ранних:** один раз установите 3.7.9 вручную. Подходящий старый закрытый ключ подписи не найден; обход проверки подписи не используется. Версии 3.7.8 и новее совместимы с текущим подписанным каналом при включённом автообновлении.

[Подробный отчёт, измерения, receipts и ограничения](https://github.com/egoist-ai1/egoist-lagom/blob/main/docs/reliability-3.7.9/README.md). Месяцы непрерывного прогона и реальная перезагрузка Windows не проверены. VPN требует работающего приложения; удалённая доставка Telegram в этом прогоне не проверена. Подпись метаданных Ed25519 не является Windows Authenticode-сертификатом.
