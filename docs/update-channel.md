# Обновления Egoist Lagom

Версия 3.7.1 начинает новый подписанный канал обновлений. При объединении каталогов прежний закрытый ключ не найден. Для перехода с предыдущих сборок установите новую версию вручную через официальный установщик. Последующие обновления проверяются новым ключом, встроенным в эту версию.

Проверка подписи, размера файла и контрольных сумм сохраняется. Ошибка проверки или недоступность канала не считаются подтверждением актуальности версии. Подпись метаданных Ed25519 не является Authenticode-подписью EXE: Windows может показать штатное предупреждение о неизвестном издателе.

## Подготовка релиза разработчиком

Закрытые ключи находятся в `.local/release-secrets`, исключены из Git и доступны текущей учётной записи Windows и SYSTEM. Не публикуйте эту папку. Для подготовки используются явный абсолютный путь к закрытому ключу и идентификатор `lagom-2026-09`. Скрипт проверяет совпадение ключа с доверенным реестром до записи релизных файлов.

```powershell
node scripts/prepare-release-assets.mjs --private-key "<absolute-path-to-release.private.pem>" --key-id lagom-2026-09
node scripts/prepare-release-assets.mjs --verify-only true
python scripts/release-github.py verify
```

Финальная публикация выполняется после проверки нового установщика в Windows 10 и Windows 11. До этой приёмки локальная сборка остаётся кандидатом.
