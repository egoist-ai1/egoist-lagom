# Egoist Lagom: завершение UI, 1 октября 2026

Исходники renderer и дизайна готовы к общей сборке. 19/19 сфокусированных тестов и 23 состояния реального headless Chromium прошли. Это приёмка интерфейса с явно обозначенными inert IPC fixtures; фоновые службы Windows она не эмулирует как доказательство работы и не подтверждает их эксплуатацию.

## Исправления

- Щит: при hover и keyboard focus чёрная connected check получает visibility:hidden сразу; остаётся отдельный белый power glyph. Обратная связь power сокращена с 300 до 100 мс. Мини-состояния ошибка, pending, выключено и устаревший ответ сохраняют доступную прокрутку.
- Один подтверждённый дефект контраста: DNS-preview endpoint имел ratio 3.6339 при 10.5px; теперь используются semantic caption 12px/muted. В final sampled text pairs минимальный ratio 5.8116.
- Серверы: убран O(n²) подсчёт серверов выбранной подписки; принадлежность нормализуется вместе с узлом. На странице и в диалоге выбора создаются максимум 60 строк. Поиск охватывает все узлы; реальный браузерный поиск достигает n1999 в списке 2000. Страницы ограничиваются актуальным размером списка. Узкий stable-ID API и подтверждение удаления выбранной подписки сохранены.
- Фоновый VPN: отдельная карточка с явным подтверждением, точным serviceInstall(nodeId string), start/stop/remove и fresh readback. Запуск требует подтверждённых процесса и автозапуска; остановка требует их выключения; удаление — отсутствия службы. Временное подключение блокируется при работе фонового режима. Имя берётся из сохранённой конфигурации службы. GUI startup не включается автоматически. Рабочий локальный процесс не объявляется проверенным внешним маршрутом; custom runtime и persistent Kill Switch для этой службы явно ограничены.
- DNS: running без verified/resolutionVerified больше не подтверждает готовность. Ответ resolver и его принадлежность показываются отдельно. Ручные поля обозначены IPv4/IPv6 без шифрования; другой control принимает HTTPS DoH. DoT, общий hostname и повреждённые строки отвергаются до команды. Порт и query реального DoH endpoint сохранены; hostname Gravityless — явный HTTPS-DoH alias.
- Новая background-карточка получила те же отступы, что существующие панели. Намерение, stale/unknown и подтверждённая готовность не смешиваются; API rejection не включает переключатель визуально.

## Проверка состояний

Изменённые VPN/DNS/Settings проверены при 1060×720, 680×450, 340×225; мини-щит при 296×340 и 148×170, hover, focus, connected, pending и read failure. Отдельно: explicit install confirmation, node ID, stop/remove, native-looking unknown payload, rejected command, exact DNS port/query, last-server search, reduced motion.23 снимка матрицы и 2 дополнительных снимка поиска/масштаба сохранены в `ui-screens/`. Все измеренные enabled control centers доступны, горизонтального overflow и page errors нет. Из 26 первоначальных состояний сохранён исходный отчёт, без повторного заявления о новой нативной проверке всех неизменённых экранов.

Масштаб 200% — browser deviceScaleFactor 2 с логическим 530×360, native Windows DPI не проверен. Снимок после подтверждения ждёт фактического завершения exit-анимации диалога. Намеренные диалоги и краткие notifications могут перекрывать информационные области; отсутствие любых наложений не заявляется.

## Воспроизводимость и границы

`ui-verify.mjs` использует production renderer/CSS, собственный loopback server и headless browser, без пользовательского курсора/фокуса. Нужно задать абсолютный LAGOM_UI_WORK_DIR в собственном task work и путь LAGOM_PLAYWRIGHT_MODULE к установленному Playwright. `ui-receipt.json` хранит raw/LF source hashes и SHA256 снимков/результатов. Изначальный baseline источник отмечен по input hashes; source state был uncommitted. Общая сборка, native IPC/SCM, установка, перезагрузка, долгий soak и внешняя VPN-связность проверяются родительской интеграцией. Не заявляется стабильность месяцами или полная доступность на основании browser fixtures.
