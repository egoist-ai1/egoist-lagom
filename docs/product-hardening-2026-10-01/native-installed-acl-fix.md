# Права установки и повторная проверка Windows

1 октября 2026 года. В подписанном кандидате `d1ea1cf54b6b6b33508f1b0edb448be169441fca` настоящий Setup завершился с кодом 0; Core запустился как LocalSystem/Auto. Следующая проверка ошибочно отклонила штатную унаследованную запись TrustedInstaller на каталоге Program Files. [Первоначальный отказ и исходные журналы](native-signed-d1ea-failure/summary.json) сохранены.

[Отдельная установка тех же подписанных байтов](native-installed-acl-capture/installer-diagnostic.json) на hosted Windows подтвердила причину: все восемь проверенных объектов принадлежат Administrators, точный TrustedInstaller имеет inherited FullControl только на каталогах установки и resources. Обычные пользователи имеют ReadAndExecute. Setup: код 0, 54.825 с; Core Running/Auto; исходная сеть сохранена. Это диагностический запуск, полная приёмка ещё требуется.

Исправлена проверка тестового стенда: точный SID TrustedInstaller разрешён только при явном `InstallationPath` в каноническом Program Files/EgoistShield. Соседний каталог, обход через `..`, относительный путь, похожий service SID, эффективный CREATOR OWNER и права записи обычного пользователя отклоняются. Для закрытых данных, backup и staging по-прежнему допускаются только SYSTEM/Administrators. Production-политика и права Windows не изменены.

Workflow старых версий теперь сохраняет отчёты исполнения в свежий `evidence/native`, отдельно от уже скачанных подписанных метаданных. Требование свежего каталога сохранено. Также исправлен список зависимостей библиотеки VPN-стенда: вместе с общими функциями импортируются их CIM, ACL и executable-resolver зависимости. Проверка библиотеки использует явно обозначенные наблюдения в памяти, без запросов SCM.

[Проверки и точные хеши](native-installed-acl-fix-evidence/receipt.json): 881/881 Node PASS, без пропусков, 23.883 с; 22/22 целевых проверок; пять допустимых и 21 отказной ACL-случай в памяти на PS7 и Windows PowerShell 5.1; actionlint и проверка diff прошли. Эти результаты не заменяют исполнение новых подписанных байтов, реального старого helper, ordinary GUI, DNS/TUN и uninstall.
