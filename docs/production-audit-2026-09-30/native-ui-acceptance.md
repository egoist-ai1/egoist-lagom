# Приёмка настоящего интерфейса 3.8.0

Проверен собранный renderer в закреплённом Electron 44.4.5 с настоящим main/preload/IPC и собственным пустым `NODE_ENV=test` профилем. Production-журнал DNS, автозапуск и системные изменения в этом режиме отключены. Нативное окно оставалось скрытым и без OS focus; Playwright подключался с `noDefaults:true`, действия использовали только pointer/keyboard собственной страницы. Состояния подключения, DOM, media и focus не эмулировались.

## Результат

- 24 комбинации: обзор, соединение, DNS, профили, Telegram, настройки при 1360×900 и 1000×680, с масштабом 100% и 200%. Горизонтальное переполнение: 0; ошибок страницы: 0; локальные шрифты загружены.
- Первоначальная проверка ширины пропустила вертикальное наложение пяти высоких разделов при 200%. Исправлены intrinsic track sizes и сжатие вложенных панелей. После изменения 10 прямых геометрических проверок дали 0 наложений; последнее действие каждого раздела достижимо настоящей прокруткой.
- Семь настоящих взаимодействий прошли: roving tabs ArrowRight/Home, hover help, Escape, постоянные descriptions и переходы полное→мини→полное. Диалог «О приложении» проверен отдельно на focus/Escape.
- Мини-щит снят при 100% и 200% с настоящим локальным pointer hover. При 200% содержимое требует прокрутки; достижимость всех нижних mini-controls отдельно не подтверждена.
- Один настоящий `forcefullyCrashRenderer` сменил renderer PID и завершил восстановление через 390 мс до `did-finish-load`. Окно осталось скрытым. Это не время первого кадра и не оценка многодневной надёжности.
- Настоящая кнопка X завершила собственный кандидат при `minimizeToTray=false`. Работающие Core/SystemDoH/Telegram установленной 3.7.9 сохранили Running/Auto и те же PID. Это не тест установленных служб 3.8.0.

Метрики без IP, адресов профиля и полного текста страницы: [native-ui/acceptance.json](native-ui/acceptance.json). Примеры: [полные настройки](native-ui/wide-settings.png), [настройки 200% в малом окне](native-ui/minimum-zoom200-settings-bottom.png), [мини-щит](native-ui/mini-idle-zoom1.png).

## Границы

Скрытый native capture не подтверждает foreground FPS, системный DPI, контраст на всех мониторах или гладкость всех переходов. `capturePage(stayHidden, stayAwake)` использовался для реальных кадров и завершения animation exit; ожидание без кадров в скрытом окне не завершало exit. Два ранних снимка после ненужной перезагрузки скрытого окна получили `UnknownVizError`; повтор без перезагрузки после fonts readiness прошёл. Этот предел harness не скрывается.

Connected-state 3.8.0 намеренно не подделывался. Отсутствие чёрной галочки под белым выключателем проверено отдельным source/state regression и настоящим ранее сохранённым connected hover 3.7.9; hover/focus-visible 3.8 используют одну CSS action-state политику. Новая installed/connected/foreground приёмка остаётся отдельным release gate.
