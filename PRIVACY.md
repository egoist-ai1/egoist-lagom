# Privacy

Egoist Lagom keeps application state, service settings and logs on the local computer. Diagnostic exports redact known secrets and subscription identifiers where possible; review an archive before sharing it.

Network requests are made only for an action selected by the user: release metadata, subscription data, public connectivity checks and configured endpoints. Device identifiers are not sent unless the user explicitly enables that option.

The public repository does not accept logs or archives containing credentials, private addresses or personal data. Use a private security report for sensitive material.
